# Full-Stack Web Development — Tədris Planı (Sillabus)

> **Müəllim:** Fariz Əsədzadə  
> **Müddət:** 9 Ay · 36 Həftə · 108 Dərs (324 saat)  
> **Qrafik:** Həftədə 3 dərs — 1. Gün (B.e), 2. Gün (Ç.a), 6. Gün (Ş.) — Hər dərs 3 saat  

9 aylıq intensiv Full-Stack Web Development peşə kursunun rəsmi tədris planı, modul strukturu və layihə tələbləri.

---

## 📌 Kursun Strukturu

| Modul | Mövzu | Müddət | Dərs Sayı | Layihə / Yekun |
|---|---|---|---|---|
| **Modul 1** | **HTML + CSS + Libraries** (Flexbox, Grid, Responsive, Tailwind CSS) | Ay 1 – 1.5 | 18 Dərs | Landing Page & Modul Tapşırığı |
| **Modul 2** | **JavaScript & Advanced JS** (DOM, Async/Await, Fetch, Axios, Open API) | Ay 1.5 – 3.5 | 24 Dərs | API Əsaslı İnteraktiv Veb Layihə |
| **Modul 3** | **React + Redux Toolkit (RTK)** (Hooks, Router v6, Context, RTK Query) | Ay 3.5 – 5 | 18 Dərs | E-Commerce Veb Tətbiqi |
| **Modul 4** | **Frontend Development with React & TypeScript** | Ay 5 – 6 | 10 Dərs | 🏆 **Orta Dönem Layihəsi (Midterm)** |
| **Modul 5** | **Backend Development with Node.js & Express** (MVC, Middleware, REST API) | Ay 6 – 7 | 11 Dərs | CRUD REST API & Frontend İnteqrasiyası |
| **Modul 6** | **MongoDB & Mongoose** (NoSQL, Validasiyalar, JWT Auth, Qorunan Marşrutlar) | Ay 7 – 8 | 11 Dərs | Tam MERN Auth & Data Sistemi |
| **Modul 7** | **Database Fundamentals (SQL & MySQL)** (Cədvəllər, Foreign Key, JOIN) | Ay 8 – 8.5 | 8 Dərs | Node.js + MySQL Əlaqəli Baza Sistemi |
| **Modul 8** | **Final Layihə & Deployment** (Vercel, Render, Docker, GitHub, Prezentasiya) | Ay 8.5 – 9 | 8 Dərs | 🎓 **Böyük Final Layihəsi & Məzuniyyət** |
